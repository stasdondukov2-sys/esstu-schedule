# 🎓 ВСГУТУ Расписание Live (PWA)

Современное, быстрое и удобное веб-приложение (PWA) для просмотра расписания занятий Восточно-Сибирского государственного университета технологий и управления ([portal.esstu.ru/raspisan.htm](https://portal.esstu.ru/raspisan.htm)).

---

## ✨ Возможности

Главный экран показывает выбранное расписание, текущую или следующую пару и компактные карточки занятий. Источники, заметки и действия раскрываются внутри карточки. В нижней навигации три раздела: «Расписание», «Поиск», «Аудитории». Избранное находится в поиске; тема, экспорт, вид недели и сведения об обновлении — в меню «Ещё». Отладочный симулятор доступен только с параметром `?debug=1`.

- ⚡ **Мгновенный просмотр пар**: Больше не нужно приближать мелкие таблицы Word 97 в браузере.
- ⏱ **Режим реального времени**: Карточка «Идёт пара прямо сейчас» с таймером обратного отсчета и прогресс-баром (или обратный отсчет до конца перемены).
- 📅 **Автоопределение недели**: Автоматический расчёт I / II недели по официальному алгоритму ВСГУТУ (время Улан-Удэ, UTC+8).
- 👥 **Поддержка студентов и преподавателей**: Быстрый поиск по всем студенческим группам и кафедрам/преподавателям.
- 🌐 **CORS & Кодировка**: Встроенный микро-бэкенд с автоматическим декодированием `windows-1251` в UTF-8 и кэшированием запросов на 15 минут.
- 📱 **PWA & Офлайн-режим**: Можно установить как приложение на экран смартфона или ПК, расписание кэшируется локально.
- 🚪 **Радар аудиторий**: текущая занятость по известным расписаниям, поиск аудитории и корпуса.
- ⭐ **Избранное**: быстрые закладки групп и преподавателей.
- 📆 **Экспорт .ics и прямые ссылки**: календарь с временем Улан-Удэ и выбранной чётностью недели.
- 🏃 **Смена корпуса**: подсказка между парами; можно выбрать свою подгруппу.
- 🔎 **Поиск преподавателей**: фамилия с `ё/е`, предмет, кафедра, аудитория и корпус. Если сохранённых файлов кафедр нет, сборка восстанавливает преподавателей из расписаний групп. Такие данные помечены как неполные. Неизвестные фамилии не создают вымышленные занятия.
- 🏛 **Официальные кафедры**: `sync_departments.py` загружает каталоги и связанные `Caf*.htm` из обоих разделов портала без генерации тестовых данных. Основной источник — кафедры; группы дополняют отсутствующие занятия. У каждой пары указана ссылка на исходный файл.
- 🔄 **Обновления и свежесть**: дата проверки источника отделена от даты сборки; офлайн-копия помечается явно. Новая версия приложения устанавливается кнопкой в баннере. Избранное и заметки сохраняются.
- ⚡ **Изменения расписания**: сравнение с предыдущей загрузкой на этом устройстве учитывает все занятия, переносы, замены и удаления. Первая загрузка не считается изменением.
- 🚪 **Планирование аудиторий**: выбор недели, дня и пары; режимы «Сейчас» и «Следующая пара». Пометка `и/д` не создаёт отдельную аудиторию.
- 📝 **Локальные заметки**: Возможность прикрепить заметку или домашнее задание к любой паре.
- 🌙 **Тёмная тема**: Комфортный просмотр в любое время суток.

## 🚀 Быстрый старт

### Требования
- Python 3.9+; основной CI использует Python 3.11.
- Node.js 22 для пересборки CSS. Готовый `static/app.css` включён в репозиторий.

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск сервера
```bash
python app.py
```
После запуска откройте в браузере: **`http://localhost:8000`**

Для обновления официальных снимков кафедр и групп выполните `python sync_esstu.py`, затем `python build_static_site.py`. Полная синхронизация запускается каждые три часа (запуск GitHub может задерживаться) и вручную с флажком `full_sync`. При обычной публикации кода обновляются кафедры, а группы берутся из сохранённых снимков, чтобы не задерживать выпуск интерфейса. Предыдущие рабочие снимки сохраняются при ошибках портала; файл с именем другой группы не публикуется под чужим номером. Кнопка «Обновить» на статическом сайте проверяет опубликованную выгрузку, а не запускает новую синхронизацию портала.

## Интерфейс и ограничения данных

В меню «⋯» доступны подгруппа (настройка сохраняется отдельно для каждой группы), сессия и условная схема корпусов. Фильтр оставляет общие и неоднозначные занятия и применяется к дню, неделе, счётчикам, блоку «Сейчас / Далее» и календарю. На преподавателей он не действует. Личные записи сессии хранятся только в этом браузере для выбранного расписания; дата в прошлом не означает сдачу. Даты без года не получают обратный отсчёт и не экспортируются в .ics.

Схема корпусов строится из обозначений известных аудиторий; это каталог для перехода к занятости, без географического масштаба и непроверенных переходов. Ссылки `?action=now`, `?action=rooms`, `?action=session`, `?action=campus` открывают соответствующие разделы после загрузки расписания. Ярлыки описаны в manifest.json с относительными URL и локальными PNG-иконками; отображение меню ярлыков зависит от платформы установленного PWA.

Календарная лента показывает даты текущей I/II недели или соседней недели при переключении; отдельные даты сессии остаются как в источнике. Карточка «Сейчас / Далее» показывает все одновременные занятия и прогресс текущей пары. Цветная полоска дополняет текстовый тип занятия. Корпус определяется только по формату обозначения аудитории, без вычисления этажей и адресов; при неизвестных или разных корпусах внутри одной пары предупреждение о переходе не показывается.

## 📡 REST API

Неверный раздел или неполный URL возвращает 400/404. Каталоги кафедр доступны для `bakalavriat` и `spezialitet`; группы — для всех четырёх разделов.

- `GET /api/rooms` — обратный индекс известных аудиторий; один слот содержит список занятий. Для GitHub Pages сборка создаёт `api/rooms.json`. Отсутствие занятия не гарантирует доступность кабинета.

- `GET /api/status` — текущее время в Улан-Удэ (UTC+8) и номер недели (I или II).
- `GET /api/groups?section=bakalavriat` — список всех групп выбранного отделения.
- `GET /api/schedule/:section/:groupId` — расписание конкретной группы по дням и неделям.
- `GET /api/departments?section=bakalavriat` — институты и кафедры.
- `GET /api/department/:section/:cafId` — расписание преподавателей кафедры.
- `GET /api/teachers/all?section=bakalavriat` — единый список всех преподавателей с расписанием.

## Публикация и разработка

Основной сайт — [GitHub Pages](https://stasdondukov2-sys.github.io/esstu-schedule/). Он работает с JSON, созданными `build_static_site.py`; `app.py` на Pages не запускается. `Procfile` и `render.yaml` предназначены для альтернативного динамического размещения.

Оформление раздаётся локально, без Tailwind CDN и Google Fonts. Для изменения классов выполните `npm ci --ignore-scripts`, затем `npm run build:css` и `python build_static_site.py`. Сборка CSS устроена по [официальной схеме Tailwind CLI](https://tailwindcss.com/docs/installation/tailwind-cli). Сгенерированный CSS сохраняется вместе с кодом. На Windows с неверным пользовательским npm script-shell можно запустить `node node_modules/@tailwindcss/cli/dist/index.mjs -i styles/input.css -o static/app.css --minify`.

`app.py` хранит снимки в `cache_store/`, либо в каталоге `ESSTU_SNAPSHOT_DIR`. На эфемерном хостинге укажите подключённый постоянный диск; файловый кэш сам по себе не переживает удаление диска. Режим источника, дата проверки и HTTP Last-Modified — отдельные поля. Сохранённая копия не считается новой проверкой портала. Проверка TLS-сертификатов включена.

Проверки: `python -m unittest test_rooms test_teachers test_sync test_study test_audit test_p0`; затем `node test_teacher_search.cjs`, `node test_experience.cjs`, `node test_sw.cjs`, `node test_campus.cjs`, `node test_study.cjs`, `node test_reference.cjs`, `node test_assets.cjs`, `node test_avatars.cjs`. Для поиска преподавателей сначала нужна статическая сборка.

## Публичные профили и фотографии

Публичный `app.py` работает только на чтение: изменение профилей через POST отключено (405), CORS не разрешает POST. Неверные/большие Content-Length возвращают 400, предел — 8 КБ. Форма редактирования удалена. Инициалы преподавателей генерируются в браузере без внешних сервисов. Для настоящей фотографии владелец помещает проверенный PNG/JPG/WebP в `static/avatars/` и указывает `photo: "avatars/name.webp"` в `teachers_meta.json`. Внешние URL и SVG для photo запрещены, файл должен существовать. Подробнее: [проверки P0](docs/P0.md).
