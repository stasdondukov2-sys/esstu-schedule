# Параллельные занятия вместо заглушек

18 октября 2026. Дополнение к исправлению аудиторных пометок, PR #24.

Скриншот группы 564-2 показал отдельный дефект: строка
`лаб.Операционные системы ГЛУШКОВА И.И. а.25-214 д/к ГАРМАЕВ Ч.Б. - а.25-312 д/к`
содержит один предмет и две последовательные пары «преподаватель — аудитория».
Прежний парсер заменял всю ячейку предупреждением о нескольких аудиториях.

Теперь такие записи разделяются по проверенным границам. Общее название
и тип занятия наследуются вторым преподавателем только в пределах исходной
ячейки. Разные явно указанные предметы и подгруппы сохраняются отдельно;
номера подгрупп из порядка преподавателей не выводятся. `raw` содержит
сегмент исходника, `source_cell_raw` — полный контекст, `subject_inherited`
и `type_inherited` отмечают наследование.

Раздельные списки преподавателей и аудиторий не связываются по индексу.
При неполном номере, неизвестной пометке или недостаточных данных остаётся
предупреждение. В карточке при этом показывается доступное исходное название
предмета, а повторяющиеся языковые варианты сокращаются без удаления сырого
текста из раскрытия. Общая фраза «Несколько занятий — сверьте с источником»
больше не заменяет доступное название в интерфейсе.

На сохранённых HTML:

- У 564-2 восстановлены все восемь проблемных ячеек (16 занятий), предупреждений нет.
- Общие предупреждения о нескольких занятиях: 210 → 131.
- Записи «Предмет не указан»: 169 → 8. Во многих ячейках предмет был указан
  один раз перед первым преподавателем и терялся при прежнем разделении.
- Для неразрешимых списков сохранены предупреждение, исходный текст и ссылка
  на источник. Поля преподавателя и аудитории не заполняются догадками.

[Предпросмотр карточек 564-2](screenshots/parallel-564-2.png): сохранённые HTML,
понедельник I недели, мобильная ширина. Это локальный предпросмотр.

Проверки: 190 Python-тестов + 9 subtests, JS-тесты, четыре целевых браузерных
сценария. Браузер проверяет реальные занятия 564-2, обе аудитории, открытие
профиля Гармаева Ч.Б., а также раскрытие неразрешимого исходника. В эталоне
zo2 обновлены четыре ячейки с общим названием иностранного языка; исходные
HTML, их SHA, преподаватели, аудитории и сырой текст сохранены.

Выпуск использует автоматическую пересборку API при смене parser_revision.
