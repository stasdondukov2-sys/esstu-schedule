# Разбор пометок после аудитории

18 октября 2026. Причина массового «Не удалось разобрать занятие»: прежний
разбор ожидал номер аудитории в самом конце строки. Служебные пометки
`смук`, `д/к пгс`, `л/пгс`, `и/дэкол` и варианты `а.дист./об.` мешали
выделить аудиторию, а затем преподавателя.

Добавлено распознавание полных известных обозначений. Неизвестный остаток
не отбрасывается: занятие продолжает требовать сверки. Прежние успешно
разобранные обозначения сохраняются. Пометки доступны в `room_note` и
`teacher_note`, видны при раскрытии карточки; исходный `raw` сохранён.
`СМАДИД` после ФИО отделяется от преподавателя. Варианты дистанционного
формата становятся онлайн-занятиями и исключаются из физических аудиторий.

Примеры:

| Исходный фрагмент | Результат |
|---|---|
| `ХАДЫКОВ М.Т. а.8233 смук` | Хадыков М.Т., ауд. 8233, пометка смук |
| `РИНЧИНОВА С.Б. а.8236 и/дэкол` | Ринчинова С.Б., ауд. 8236 и/д, пометка экол |
| `ДОРЖИЕВА Е.В. СМАДИД а.1-67` | Доржиева Е.В., ауд. 1-67, пометка СМАДИД |
| `ДАМДИНЖАПОВ Б.Ц. а.дистанц.` | Дамдинжапов Б.Ц., онлайн |
| `САМБУЕВ Г.Ж. - а.25-212 д/к` | Предмет не указан; предупреждение сохранено |

В замороженном наборе найдено 919 записей с прежним общим сообщением,
527 уникальных строк. Из них 918 записей (526 уникальных строк) получили
предмет, преподавателя и аудиторию; у оставшейся строки предмет отсутствует
в самом источнике. Это результат на сохранённых HTML, не обещание нулевого
числа предупреждений на меняющемся портале. Другие предупреждения, в том
числе неоднозначные ячейки с несколькими занятиями, не отключены.

Локально: Ruff, 179 Python-тестов и 9 subtests, JS-проверки. Проверка в
браузере использует настоящий сохранённый HTML: обе пары «Основы
безопасности и защиты Родины» теперь имеют преподавателя и аудиторию.
Изменён только ожидаемый JSON этих двух занятий; исходные HTML и их SHA
не менялись. Отрицательные тесты сохраняют предупреждение для неизвестных
хвостов, нескольких аудиторий и отсутствующего предмета.

При выпуске изменение parser_revision автоматически пересобирает API из
сохранённых исходников ветки data. Новая загрузка всего портала не нужна.
