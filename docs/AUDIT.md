Проверены локальные исходники, static/, Service Worker, workflow, сборка по сохранённым источникам и браузер. Ниже разделены внесённые исправления, неверные предположения исходного разбора и ограничения, которые остаются.

## Неточности исходного разбора

- `month <= 7` в Python означает январь–июль. Август уже использует текущий год; JS использует соответствующие месяцы с нулевой нумерацией. Ошибка была в вычислении понедельника, а не в выборе года для августа.
- `lang="ru"` уже был указан. Основные модальные окна уже имеют role/aria-modal, Esc, возврат и удержание фокуса.
- Баннер обновления скрыт классом hidden и появляется после обнаружения ожидающего Service Worker.
- При первом открытии уже автоматически загружается группа по умолчанию. «Выберите расписание» — первоначальный текст до загрузки, а не обязательный пустой экран.
- Нижние кнопки имели текстовые доступные названия; SVG добавлены для предсказуемого внешнего вида.
- Отсутствие lxml само по себе не является ошибкой; добавлять второй парсер без измерения и проверки совместимости не требовалось.

## Что остаётся

- HTML стороннего портала не имеет стабильной схемы. Нужны дополнительные реальные фикстуры при каждом изменении формата; произвольная расстановка предметов/преподавателей/аудиторий пока не разбирается универсально.
- По одному сочетанию фамилии и инициалов нельзя надёжно различить разных людей. До появления подтверждённых идентификаторов/полных ФИО коллизии каталога возможны; автоматически назначать вымышленные ID людям нельзя.
- Полный перенос всех файлов в src/tests, единая типизированная модель, устранение всех повторений статического/динамического режимов — отдельная миграция. Общие parser/catalog/teachers/rooms уже используются обоими режимами частично.
- Gzip для необязательного Python-сервера не добавлен; ETag уже снижает повторную передачу. Правила часового пояса пока используют известное UTC+8, а не базу zoneinfo.
- Эфемерный диск не становится постоянным от смены кода. На таком хостинге нужен подключённый том. В последующем исправлении [P0](P0.md) публичная запись профилей полностью отключена; на GitHub Pages её также нет.
- На момент проверки `npm audit` сообщает четыре high-предупреждения в dev-цепочке CLI → @parcel/watcher → micromatch → braces (GHSA-vfj7-8cjw-p6xm). Используется однократная сборка доверенных исходников, без --watch; код сборщика не отправляется браузеру. Доступной исправленной версии braces в реестре не найдено. Это зафиксированное ограничение, а не заявление об отсутствии уязвимостей.
- Лицензия требует выбора владельца. Description/topics GitHub и отдельные скриншоты относятся к оформлению репозитория и здесь не менялись.
